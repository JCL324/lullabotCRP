# lullabotCRP
## Lullabot Code Review Project

The goal of this task is twofold. It gives you a chance to work with the tooling the Support & Maintenance team uses every day, like Drainpipe, Tugboat, and managed Drupal hosting, so you can decide whether this work genuinely interests you. It also gives us a look at your work product, including how you navigate setup, documentation, and any friction along the way.

### What I'll be looking at:
- A functional Drupal site running on both Tugboat and your chosen hosting provider
- The repository itself, with particular attention to composer.json, .tugboat/config.yml, and any hosting configuration files
- Clear Git commit messages that describe the changes being made
